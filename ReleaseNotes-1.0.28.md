# Hexor 1.0.28

## Daily Activities: steps now finish when the game says so
- The daily routine no longer switches activities after a fixed time. Each step now runs until the game itself reports it finished: daily tasks are done, the Auto Krao Dungeon run is over, today's kinah reaches its daily target, or the gathering time is up. This fixes the routine stopping or switching mid-action after a few seconds.
- Steps completed earlier the same day are skipped when the sequence starts again, and the routine says so instead of redoing them.
- After the last step, the after-finish choice works as before: "Start gathering" keeps the character online and busy, and "Close the game" stops everything and closes the game.
- If the game pauses automation because of an authorization problem — the most common cause is the automation card being signed in on another computer — the routine page now explains why the character is standing still and resumes by itself once the game allows automation again.

## Installation
- This update installs automatically: at launch and while the console is open. The console restarts itself after the install.
