# Hexor Control Center 1.0.22

## Fixes

- **Gathering list no longer wipes itself.** The saved gather targets now survive updater installs and in-game rewrites: if the saved list disappears, Hexor rebuilds it from its own saved copy automatically instead of leaving the filter empty.
- **Hidden Cube now displays correctly** in the resource list, and every known resource always shows an English name.

## Improvements

- **Live Control page hidden** — it had no customer use yet.
- **"Clean Up Hexor Files" is now "Remove Bot Module"** — clearer wording for what the button does, and bot module detection now finds Steam installations directly instead of relying on the slow full-drive scan.
