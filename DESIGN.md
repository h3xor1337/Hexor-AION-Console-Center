# Hexor Design System

## Visual World

Hexor is a midnight transit-console: a deep violet-black control surface organized by precise route lines, interchange points, and calm porcelain-white text. It is an original functional translation of navigation clarity for a gaming settings tool, not a reproduction of any existing product.

## Operate Surface

The application shell prioritizes fast scanning: a compact branded rail, selected-route indicator, status line, and generous settings canvas. The updater is a persistent bottom-rail action rather than content competing with settings.

## Tokens

- Ink: `#0B0912`; panel: `#141120`; raised surface: `#1B1728`.
- Porcelain text: `#F5F1FF`; muted lavender: `#B9ADCA`.
- Route violet: `#9667E7`; route blue: `#6E8CF4`; route amber: `#E0A94D`.
- System font: Segoe UI Variable / Segoe UI, selected because no licensed custom font asset is present.
- Corners: 10px controls, 16px primary surfaces. Elevation uses a soft offset shadow without a competing card border.

## Interaction

Hover and pressed states use 160ms easing. Keyboard focus uses a high-contrast violet ring. Reduced-motion users receive static state changes. The title bar maintains native drag, resize, maximize/restore, snap, taskbar, and Alt+Tab behavior.
