# Hexor 1.0.30

## German and Japanese
- The console is now fully available in Deutsch and 日本語 — every page, button, status message, dialog and update flow, alongside English, 简体中文 and 한국어.
- Switching languages re-renders the entire console immediately.

## Smaller downloads for this update and beyond
- Consoles updated to 1.0.29 or later now download the console-only package (about 60 MB) instead of the full package; older installations automatically use the complete package for this one update.
- If an update download was interrupted earlier, the next attempt reuses the already downloaded package when it matches the signed release.

## Installation
- This update installs automatically: at launch and while the console is open. The console restarts itself after the install.
