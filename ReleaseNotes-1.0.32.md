# Hexor 1.0.32

## Six more console languages
The console is now fully available in ten languages: English, 简体中文, 繁體中文, 한국어, 日本語, Русский, Español, Português, Français and Italiano — every page, button, status message, dialog and update flow, matching the languages offered in the game's own menu.

## In-game language options expanded
The in-game interface language selector now offers every language supported by the latest automation module update, and your console language can set the game language in one step.

## CAPTCHA status now follows your language
The CAPTCHA page status line no longer stays in English when you switch languages; it re-renders with the rest of the console.

## Installation
This update installs automatically: at launch and while the console is open. The console restarts itself after the install.
