# Hexor 1.0.29

## Fresh new look
- The whole console has been restyled: new sidebar icons with a highlighted active tab, smooth page transitions when switching tabs, cleaner buttons (primary / secondary / destructive), aligned forms, a slim progress bar, modern checkboxes and radio buttons, and a pinned status bar at the bottom.
- New brand icon and logo integrated throughout the app and in the taskbar / desktop icon.

## Full language support
- The console now translates fully into 简体中文 and 한국어 — every page, button, status message and dialog, not just the navigation.
- Switching languages now re-renders the entire console immediately, including status tiles and update panels.

## Smaller, faster updates
- Update downloads are now about half the previous size, so installing an update downloads roughly 60 MB instead of 110 MB and finishes sooner on slower connections.
- If an update download was interrupted earlier, the next attempt reuses the already downloaded package when it matches the signed release, instead of downloading everything again.
- Old, finished or abandoned update files are cleaned up automatically, freeing the disk space they were holding.
- An interrupted or failed update no longer leaves the console stuck: the next check simply picks up where it safely can.

## Fixes
- The update dialog now centers on the screen instead of over the console window.

## Installation
- This update installs automatically: at launch and while the console is open. The console restarts itself after the install.
